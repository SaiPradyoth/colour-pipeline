About This Tool
Built for high-precision spectral color characterization.

This web application converts full absorbance spectra into CIE XYZ, CIE Lab, and ΔE values using a standardized pipeline under illuminant D65. It is designed for workflows such as 96-well plate spectroscopy where subtle wavelength shifts and color changes need to be tracked numerically.

  • Upload plate datasets directly from your spectrometer export (.xlsx).
  • Automatically detect wells and highlight missing or incomplete data.
  • Compute CIE XYZ → CIE Lab → ΔE per well relative to a chosen reference.
  • Export results as CSV for analysis or PDF for reporting.
