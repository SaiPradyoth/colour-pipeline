About

This tool converts absorbance spectra → XYZ → Lab → ΔE2000 and lets you explore well-to-well differences via a plate heatmap, spectral overlays, and the full raw data matrix.

  • Absorbance spectra: How much light each well absorbs at each wavelength — like a rainbow measured with numbers.
  • XYZ: A color model:
    • X ≈ red content
    • Y ≈ green / brightness
    • Z ≈ blue content
  • Lab (L*, a*, b*): A color space based on human vision:
    • L* = light ↔ dark
    • a* = red (+) ↔ green (–)
    • b* = yellow (+) ↔ blue (–)
  • ΔE2000: How different two colors are (0 = identical; higher = more different).
  • Reference well: The well chosen as the starting color for ΔE comparison.
  • Plate type: Number of wells on the microplate (48, 96, 384).
    • Illuminant: The assumed light source (daylight / warm light / cool light).
    • D65: Standard noon daylight
    • D50: Soft afternoon daylight
    • A: Warm tungsten indoor light
    • F2: Cool fluorescent light
    • E: Equal-energy reference light
  • Observer angle: The viewing geometry of the “virtual eye” (2° or 10°).
  • ΔE heatmap: A colored map showing which wells are similar or different.
  • Spectral curves: Smooth lines showing absorbance vs wavelength.
  • Raw data matrix: The complete table of all original spectrometer values.
