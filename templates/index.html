About this tool
Quick guide for scientists and engineers using the spectral color pipeline.

This web app converts full absorbance spectra into standardized color coordinates using CIE 1931 colorimetry. For each well we compute:

  • XYZ – Tristimulus values under CIE D65 illuminant
  • L*, a*, b* – CIE Lab coordinates (perceptually uniform space)
  • ΔE – Color difference between each well and a chosen reference well

The pipeline is implemented in Python using colour-science, pandas, and numpy, wrapped in a Flask app. This UI layer is designed so you can drop in new plate exports and immediately obtain reproducible numeric “color signatures” suitable for automation and screening.
