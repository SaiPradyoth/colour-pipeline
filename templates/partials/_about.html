About

This tool converts absorbance spectra → XYZ → Lab → ΔE2000 and lets you explore well-to-well differences via a plate heatmap, spectral overlays, and the full raw data matrix.

  • Absorbance spectra: Light absorption per wavelength.
  • XYZ: Color-space tristimulus values.
  • Lab: Perceptual color space (L*, a*, b*).
  • ΔE2000: Numerical difference between colors.
  • Reference Target: The ΔE = 0 “anchor” color (white tile / buffer / black / custom).
  • Blank Wells: Background subtraction wells (buffer / ultrapure water).
  • Plate type: Choose 48, 96, or 384 wells.
  • Illuminant: Light source model (D65, D50, A, F2, E).
    • D65: Standard noon daylight
    • D50: Soft daylight
    • A: Tungsten light
    • F2: Fluorescent
    • E: Equal-energy
  • Observer angle: 2° (standard) or 10° (wide field).
  • Heatmap: Visual ΔE pattern across the plate.
  • Spectral curves: Visual absorbance vs wavelength.
  • Raw matrix: The underlying spectrometer data.
  • Metadata: Optional file that labels each well (sample, AuNP, contents, category).
